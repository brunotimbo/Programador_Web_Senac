# Curso Desenvolvedor Web — Senac

## 📚 Sobre o projeto

Este repositório foi criado para armazenar os conteúdos, exercícios, atividades e projetos desenvolvidos durante o curso de **Desenvolvedor Web do Senac**.

O objetivo é acompanhar minha evolução no aprendizado de desenvolvimento web, desde os conceitos básicos até a criação de páginas e aplicações mais completas.

---

## 🚀 Conteúdos estudados

Durante o curso, serão adicionados conteúdos relacionados a:

* HTML5
* CSS3
* JavaScript
* Git e GitHub
* Desenvolvimento de interfaces
* Estruturação de páginas web
* Componentes e layouts
* Responsividade
* Projetos práticos
